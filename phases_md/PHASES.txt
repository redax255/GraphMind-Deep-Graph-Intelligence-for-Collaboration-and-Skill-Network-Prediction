# 1. VUE D'ENSEMBLE DU PROJET

## 1.1 Informations du projet

**Titre complet** : Analyse Graph ML de l'écosystème tech marocain - Prédiction de collaborations et recommandations

**Objectif principal** : Construire un système intelligent basé sur Graph Machine Learning pour :
- Analyser le réseau professionnel tech au Maroc
- Identifier les relations et collaborations entre professionnels
- Prédire les collaborations futures
- Recommander des connexions pertinentes

**Contexte** : Premier projet de ce type au Maroc. Analyse de l'écosystème tech marocain (Data Scientists, ML Engineers, Développeurs) pour cartographier le réseau professionnel et fournir des insights sur les compétences, entreprises et parcours.

**Technologies clés** :
- **Backend & Data** : Python, MongoDB, NetworkX
- **Graph ML** : PyTorch Geometric, GraphSAGE, GCN, node2vec
- **ML Classique** : Scikit-learn, XGBoost
- **Visualisation** : Matplotlib, Plotly, t-SNE/UMAP

## 1.2 Valeur et applications

**Pourquoi ce projet ?**
- 🇲🇦 **Originalité** : Aucun projet similaire n'existe sur le marché marocain
- 📊 **Insights business** : Données uniques sur l'écosystème tech marocain
- 🎓 **Portfolio technique** : Démontre expertise en NLP, Graph Theory, Deep Learning
- 💼 **Applications réelles** : Recrutement, networking, analyse de marché

**Applications concrètes** :
1. **Pour les recruteurs** : Identifier talents et leur réseau
2. **Pour les startups** : Trouver des profils complémentaires
3. **Pour les investisseurs** : Analyser l'écosystème tech marocain
4. **Pour les écoles** : Suivre le placement des alumni
5. **Pour les professionnels** : Recommandations de connexions

**Valeur ajoutée** :
- Cartographie complète du réseau tech marocain
- Insights sur les flux de talents entre entreprises
- Identification des compétences émergentes
- Prédiction des collaborations futures avec ML

- Le champ `resume` (exemple : "Expert en Python, SQL, Spark...")
- Les `description` dans `experience[]` (exemple : "Utilisation de React, Node.js...")

## PHASE 2 : NETTOYAGE & PREPROCESSING (2 SEMAINES)

**Objectif** : Transformer les données brutes en données propres et exploitables pour le Graph ML.

### SEMAINE 1 : NETTOYAGE

#### 2.1.1 Dédoublonnage des profils (Jours 1-2)

**Problème** : Profils en double (même personne apparaît plusieurs fois).

**Tâches** :
1. Identifier profils en double (critères : même nom + même première entreprise)
2. Comparer similarité avec fuzzy matching (seuil 85%)
3. Pour chaque doublon, décider quelle version garder :
   - Garder le profil le plus complet (plus de compétences, expériences, formations)
   - Ou fusionner les 2 profils (prendre toutes les données des 2)
4. Documenter toutes les décisions dans un fichier log

**Méthode** :
- Utiliser `fuzzywuzzy` pour matching de noms
- Créer un score de complétude par profil
- Sauvegarder les paires de doublons avant suppression

**Résultat attendu** : 0-5% de doublons supprimés (~0-50 profils)

#### 2.1.2 Normalisation des entreprises (Jours 3-5)

**Problème** : Même entreprise avec multiples variantes.
- Exemple : "Google Inc", "Google LLC", "Google", "GOOGLE", "Google France"

**Tâches** :
1. Extraire toutes les entreprises uniques
2. Créer dictionnaire de mapping manuel pour top 50 entreprises marocaines :
   - SQLI Maroc → SQLI

### SEMAINE 2 : PREPROCESSING AVANCÉ

#### 2.2.1 Parsing et validation des dates (Jours 8-10)

**Problème** : Dates dans formats multiples et en français.

**Formats à gérer** :
```
"juil. 2024"           → "2024-07"
"juillet 2024"         → "2024-07"
"07/2024"              → "2024-07"
"2024"                 → "2024-01"
"aujourd'hui"          → Date actuelle
"Présent"              → Date actuelle
"oct. 2023 - aujourd'hui · 2 ans 1 mois"  → Parser les 2 dates
```

**Tâches** :
1. Créer fonction de parsing multi-formats
2. Gérer mois en français (mapping : "juil" → 07, "oct" → 10, etc.)
3. Gérer postes actuels : "aujourd'hui", "Présent", "Now" → `datetime.now()`
4. Valider cohérence : `date_fin > date_debut`
5. Calculer durée de chaque expérience en mois

**Cas spéciaux** :
- Expériences avec période globale (ex: "Criteo - 4 ans 2 mois") ET sous-expériences
- Dates manquantes → marquer comme `null` et documenter

**Validation** :
```python
# Vérifier toutes les expériences
for profile in profiles:
    for exp in profile['experience']:
        assert exp['date_fin'] > exp['date_debut'] or exp['date_fin'] is None
```

**Résultat attendu** : 100% des dates dans format YYYY-MM, 0% d'erreurs de cohérence.

**Algorithme de détection des collaborations** :

```python
from datetime import datetime

def detect_collaborations(profiles, min_overlap_months=6):
    """
    Détecte les collaborations basées sur chevauchements temporels
    """
    collaborations = []
    
    # Grouper par entreprise
    profiles_by_company = {}
    for profile in profiles:
        for exp in profile['experience']:
            company = exp['company']
            if company not in profiles_by_company:
                profiles_by_company[company] = []
            profiles_by_company[company].append({
                'profile_id': profile['id'],
                'date_debut': exp['date_debut'],
                'date_fin': exp['date_fin']
            })
    
    # Pour chaque entreprise avec 2+ profils
    for company, workers in profiles_by_company.items():
        if len(workers) < 2:
            continue
        
        # Comparer toutes les paires
        for i in range(len(workers)):
            for j in range(i+1, len(workers)):
                w1, w2 = workers[i], workers[j]
                
                # Calculer chevauchement temporel
                start = max(w1['date_debut'], w2['date_debut'])
                end = min(w1['date_fin'], w2['date_fin'])
                
                if start < end:
                    overlap_months = (end - start).days / 30
                    
                    if overlap_months >= min_overlap_months:
                        collaborations.append({
                            'profil_a': w1['profile_id'],
                            'profil_b': w2['profile_id'],
                            'entreprise': company,
                            'duree_mois': overlap_months,
                            'force': min(overlap_months / 24, 1.0)  # max 1.0
                        })
    
    return collaborations

# Détecter collaborations
collaborations = detect_collaborations(profiles_clean)

# Ajouter au graphe

    G.add_edge(
        collab['profil_a'],

        edge_type='A_COLLABORE_AVEC',
        entreprise=collab['entreprise'],
        duree_mois=collab['duree_mois'],

    )
```

```python
from sklearn.metrics import jaccard_score

def calculate_skill_similarity(profile_a, profile_b):
    """
    Calcule similarité basée sur compétences communes
    """
    skills_a = set(profile_a['skills'])
    skills_b = set(profile_b['skills'])
    
    common = skills_a.intersection(skills_b)
    union = skills_a.union(skills_b)
    
    if len(union) == 0:
        return 0, []
    
    jaccard = len(common) / len(union)
    return jaccard, list(common)

# Pour toutes les paires de profils
for i, prof_a in enumerate(profiles_clean):
    for prof_b in profiles_clean[i+1:]:
        similarity, common_skills = calculate_skill_similarity(prof_a, prof_b)
        
        # Seuil minimum : 3 compétences communes
        if len(common_skills) >= 3:
            G.add_edge(
                prof_a['id'],
                prof_b['id'],
                edge_type='COMPETENCE_COMMUNE',
                nb_competences_communes=len(common_skills),
                competences=common_skills,
                score_similarite=similarity
            )
```

## PHASE 4 : GRAPH ML - EMBEDDINGS (2 SEMAINES)

**Objectif** : Apprendre des représentations vectorielles (embeddings) des nœuds pour capturer la structure du graphe.

### 4.1 Concepts clés

**Qu'est-ce qu'un embedding ?**

Un embedding est une **représentation vectorielle** d'un nœud dans un espace de dimensions réduites qui capture :
- Sa position dans le graphe
- Ses relations avec d'autres nœuds
- Sa similarité structurale

**Exemple concret** :
```
Avant (nœud symbolique) :
  Alice = "profil_123"

Après embedding (vecteur de 128 dimensions) :
  Alice = [0.34, -0.12, 0.87, 0.45, ..., -0.23, 0.91]

Bob (profil similaire à Alice) :
  Bob = [0.31, -0.15, 0.89, 0.42, ..., -0.21, 0.88]
  
→ Distance faible entre Alice et Bob = Profils similaires
```

**Pourquoi c'est utile ?**
- Permet de calculer similarité entre profils
- Input pour modèles de Machine Learning
- Visualisation en 2D/3D (t-SNE, UMAP)
- Clustering automatique

### SEMAINE 1 : MÉTHODE BASELINE (node2vec)

#### 4.2.1 Préparation (Jours 1-2)

**Jour 1 : Comprendre node2vec**

**Principe** : node2vec génère des "random walks" sur le graphe (comme un parcours aléatoire), puis apprend des embeddings avec Word2Vec.

**Analogie** : 
- Imagine que tu te promènes aléatoirement dans le graphe
- Tu notes les nœuds que tu visites : "Alice → Python → Bob → SQL → Alice"
- Tu répètes ça 1000 fois
- Word2Vec apprend que les nœuds visités ensemble sont similaires

**Hyperparamètres clés** :
```python
dimensions = 128      # Taille du vecteur embedding
walk_length = 80      # Longueur de chaque promenade
num_walks = 10        # Nombre de promenades par nœud
p = 1                 # Return parameter
q = 1                 # In-out parameter
window = 10           # Context window (Word2Vec)
```

#### 4.2.2 Entraînement node2vec (Jours 3-4)


**Jour 8 : Définir le modèle GraphSAGE**

```python
import torch
import torch.nn.functional as F
from torch_geometric.nn import SAGEConv

class GraphSAGE(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GraphSAGE, self).__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = SAGEConv(hidden_channels, out_channels)
    
    def encode(self, x, edge_index):
        # Première couche
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        
        # Deuxième couche
        x = self.conv2(x, edge_index)
        return x
    
    def decode(self, z, edge_index):
        # Produit scalaire des embeddings
        return (z[edge_index[0]] * z[edge_index[1]]).sum(dim=-1)
    
    def forward(self, x, edge_index, edge_label_index):
        z = self.encode(x, edge_index)
        return self.decode(z, edge_label_index)

# Créer modèle
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
```

```python
def train_epoch(model, data, train_edges, train_neg_edges):
    model.train()
    optimizer.zero_grad()
    
    # Forward
    z = model.encode(data.x, data.edge_index)
    
    # Positive edges
    pos_edge_index = torch.tensor(train_edges, dtype=torch.long).t()
    pos_pred = model.decode(z, pos_edge_index)
    
    # Negative edges
    neg_edge_index = torch.tensor(train_neg_edges, dtype=torch.long).t()
    neg_pred = model.decode(z, neg_edge_index)
    
    # Loss : Binary Cross Entropy
    pos_loss = F.binary_cross_entropy_with_logits(
        pos_pred, 
        torch.ones(pos_pred.size(0))
    )
    neg_loss = F.binary_cross_entropy_with_logits(
        neg_pred, 
        torch.zeros(neg_pred.size(0))
    )
    loss = pos_loss + neg_loss
    
    # Backward
    loss.backward()
    optimizer.step()
    
    return loss.item()

def evaluate(model, data, val_edges, val_neg_edges):
    model.eval()
    
    with torch.no_grad():
        z = model.encode(data.x, data.edge_index)
        
        pos_edge_index = torch.tensor(val_edges, dtype=torch.long).t()
        pos_pred = model.decode(z, pos_edge_index)
        
        neg_edge_index = torch.tensor(val_neg_edges, dtype=torch.long).t()
        neg_pred = model.decode(z, neg_edge_index)
        
        # Calculer accuracy
        pos_correct = (torch.sigmoid(pos_pred) > 0.5).sum().item()
        neg_correct = (torch.sigmoid(neg_pred) < 0.5).sum().item()
        accuracy = (pos_correct + neg_correct) / (len(val_edges) + len(val_neg_edges))
    
    return accuracy

# Entraînement (10-20 epochs)
print("Début entraînement GNN...")
for epoch in range(1, 21):
    loss = train_epoch(model, data, train_edges, train_neg_edges)
    
    if epoch % 5 == 0:
        val_acc = evaluate(model, data, val_edges, val_neg_edges)
        print(f"Epoch {epoch:02d}, Loss: {loss:.4f}, Val Acc: {val_acc:.4f}")

# Extraire embeddings finaux
model.eval()
```

```python
def create_features_for_pair(u, v, embeddings, G):
    """
    Créer vecteur de features pour une paire (u, v)
    """
    features = []
    
    # 1. Embeddings (concaténés)
    emb_u = embeddings[u]
    emb_v = embeddings[v]
    features.extend(emb_u)
    features.extend(emb_v)
    
    # 2. Produit élément par élément (Hadamard)
    hadamard = emb_u * emb_v
    features.extend(hadamard)
    
    # 3. Features structurales
    
    # Common neighbors
    neighbors_u = set(G.neighbors(u))
    neighbors_v = set(G.neighbors(v))
    common_neighbors = len(neighbors_u & neighbors_v)
    features.append(common_neighbors)
    
    # Jaccard coefficient
    jaccard = common_neighbors / len(neighbors_u | neighbors_v) if len(neighbors_u | neighbors_v) > 0 else 0
    features.append(jaccard)
    
    # Adamic-Adar
    adamic_adar = sum(1 / np.log(G.degree(w)) for w in (neighbors_u & neighbors_v) if G.degree(w) > 1)
    features.append(adamic_adar)
    
    # 4. Features métier
    
    # Compétences communes
    skills_u = set(n for n in neighbors_u if G.nodes[n].get('node_type') == 'COMPETENCE')
    skills_v = set(n for n in neighbors_v if G.nodes[n].get('node_type') == 'COMPETENCE')
    common_skills = len(skills_u & skills_v)
    features.append(common_skills)
    
    # Même secteur (entreprises communes)
    companies_u = set(n for n in neighbors_u if G.nodes[n].get('node_type') == 'ENTREPRISE')
    companies_v = set(n for n in neighbors_v if G.nodes[n].get('node_type') == 'ENTREPRISE')
    common_companies = len(companies_u & companies_v)
    features.append(common_companies)
    
    # Même école
    schools_u = set(n for n in neighbors_u if G.nodes[n].get('node_type') == 'ECOLE')
    schools_v = set(n for n in neighbors_v if G.nodes[n].get('node_type') == 'ECOLE')
    same_school = 1 if len(schools_u & schools_v) > 0 else 0
    features.append(same_school)
    
    # 5. Distance dans le graphe (shortest path)
    try:
        distance = nx.shortest_path_length(G, u, v)
    except nx.NetworkXNoPath:
        distance = 999  # Pas de chemin
    features.append(distance)
    
    return np.array(features)
```

```python
def recommend_connections(profile_id, G, embeddings, model, top_k=10):
    """
    Recommande top-K connexions pour un profil
    """
    profile_nodes = [n for n in G.nodes() if G.nodes[n].get('node_type') == 'PROFIL']
    
    candidates = []
    for candidate in profile_nodes:
        if candidate == profile_id or G.has_edge(profile_id, candidate):
            continue  # Skip si déjà connecté
        
        # Créer features
        features = create_features_for_pair(profile_id, candidate, embeddings, G)
        
        # Prédire probabilité
        proba = model.predict_proba([features])[0][1]
        
        candidates.append((candidate, proba))
    
    # Trier par probabilité
    candidates.sort(key=lambda x: x[1], reverse=True)
    return candidates[:top_k]

# Tester
test_profile = 'profil_123'
recommendations = recommend_connections(test_profile, G, embeddings_gnn, best_model)

print(f"\nTop 10 recommandations pour {G.nodes[test_profile]['nom']}:")
for node, proba in recommendations:
    print(f"  {G.nodes[node]['nom']}: {proba:.4f}")
```

**Jour 4 : Optimiser temps d'inférence**

```python
# Avant : 2.5 secondes par recommandation
# Objectif : < 1 seconde

# Solution 1 : Précalculer les embeddings
embeddings_cache = {}
for node in G.nodes():
    if G.nodes[node].get('node_type') == 'PROFIL':
        embeddings_cache[node] = embeddings_gnn[node]

# Solution 2 : Vectoriser les calculs
import numpy as np

def recommend_connections_fast(profile_id, top_k=10):
    # Calculer similarité avec tous les profils en une fois
    target_emb = embeddings_cache[profile_id]
    
    candidates = []
    embeddings_matrix = []
    candidate_ids = []
    
    for node, emb in embeddings_cache.items():
        if node != profile_id and not G.has_edge(profile_id, node):
            embeddings_matrix.append(emb)
            candidate_ids.append(node)
    
    # Calcul vectorisé de similarité cosine
    embeddings_matrix = np.array(embeddings_matrix)
    similarities = cosine_similarity([target_emb], embeddings_matrix)[0]
    
    # Top-K
    top_indices = np.argsort(similarities)[::-1][:top_k]
    
    return [(candidate_ids[i], similarities[i]) for i in top_indices]

# Test de performance
import time

recs = recommend_connections_fast('profil_123')
end = time.time()
print(f"Temps d'inférence: {end - start:.4f}s")  # < 0.5s
```
