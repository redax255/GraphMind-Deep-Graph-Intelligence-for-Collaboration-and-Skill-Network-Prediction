🚀 COMMANDES DOCKER
1. Build de l'image

docker build -t graphmind-api:latest .


2. Lancer avec Docker Compose
bash# Démarrer tous les services
docker-compose up -d

# Vérifier les logs
docker-compose logs -f graphmind-api

# Vérifier le statut
docker-compose ps



3. Arrêter les services
bashdocker-compose down



4. Supprimer tout (services + volumes)
bashdocker-compose down -v
